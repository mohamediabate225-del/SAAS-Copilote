Extension pour Chrome sur ordinateur

Installer l’extension Chrome

L’extension locale réutilise votre préparation pour ouvrir plus vite le copilote depuis votre navigateur.

Installation manuelle

  1. Lancez le serveur sur votre ordinateur.
  2. Dans Chrome, ouvrez chrome://extensions et activez le mode développeur.
  3. Choisissez « Charger l’extension non empaquetée », puis ouvrez le dossier extension du projet.
  4. Dans votre espace candidat local, ouvrez « Extension et facturation » et générez un code d’association.
  5. Collez ce code dans le volet Copilote et cliquez sur « Synchroniser ».

Le volet est destiné à Chrome sur ordinateur. Sur téléphone, utilisez le site et son mode entraînement.
