Installer l’extension Chrome

Cette version est un prototype local : l’extension n’est pas publiée sur le Chrome Web Store.

  1. Dans Chrome, ouvrez chrome://extensions.
  2. Activez Mode développeur, puis cliquez sur Charger l’extension non empaquetée.
  3. Sélectionnez le dossier C:\Users\User\Documents\Codex\2026-11-13\referenced-chatgpt-conversation-this-is-an\work\archive-review\interview-copilot\extension.
  4. Cliquez sur l’icône Extensions puis sur Copilote Entretien.
  5. Ouvrez Teams dans Chrome, sélectionnez l’onglet et partagez son audio après accord des participants.

Le serveur local doit rester ouvert. Le profil de votre compte se synchronise automatiquement avec l’extension (ou via le bouton « Synchroniser » du volet) lorsque vous êtes connecté sur votre espace web.
